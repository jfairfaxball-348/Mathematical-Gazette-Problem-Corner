# Sources and Evidence

Use this directory for source-management material that supports later stages.

## Minimum source record

For web or archive evidence, preserve:

- title/description;
- author/editor/proposer where relevant;
- journal/issue/problem identifier where relevant;
- URL or DOI;
- publication date/year if known;
- date accessed;
- access level (full, partial, metadata only);
- whether the source is current official guidance, primary historical material, or secondary commentary.

## Source priority

For current submission instructions, prefer current official journal/section sources.

For Stage 2, primary Problem Corner pages/PDFs and published solutions are preferred. Secondary indexes may help locate material but should not silently replace the primary source when primary evidence is available.

For Stage 4, breadth matters: record both positive hits and meaningful negative searches, but never describe a negative search as proof of originality.
