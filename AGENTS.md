# Agent Instructions

This is an open mathematical research repository about local-extrema deletion dynamics on finite sequences and permutations.

## Entry sequence

At the beginning of a session, inspect the live committed repository and read:

1. `authoritative/START_HERE.md`
2. `authoritative/STATE.json`
3. `PROJECT.md`
4. `STATUS.md`
5. `theory/FOUNDATIONS.md`
6. `questions/RESEARCH_QUESTIONS.md`

Current explicit human instructions override repository documents. Otherwise the committed repository is authoritative.

## Mathematical discipline

- Work with pairwise distinct real values unless a variant explicitly changes that assumption.
- Use rank normalisation freely: the base process depends only on order type.
- Distinguish carefully between original neighbours and current surviving neighbours.
- Label every substantial claim as proved, conjectural, computationally verified, or literature-derived.
- Prefer short invariant-based proofs before brute force.
- Use exhaustive computation to discover and test patterns, not as a substitute for general proof.
- When counting permutations, state conventions for alternating permutations and up/down runs explicitly.
- Do not claim originality merely because a search found nothing.

## Research hygiene

Preserve useful counterexamples, failed conjectures and exact computational ranges. When a conjecture is disproved, record the smallest counterexample if practical. When a theorem is strengthened, keep the strongest clean formulation and its proof.

Avoid publication-workflow scaffolding. This repository is for mathematical theory, experiments, literature connections and open questions.
