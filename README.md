# Mathematical Gazette Problem Corner

A staged project to develop an original problem suitable for **The Mathematical Gazette — Problem Corner**.

The governing design principle is:

> **simple situation → natural question → unexpected answer → elegant mathematics**

## Current state

Stage 1 (Scaffold / Bootstrap) is complete. Stage 2 (Research) is the next stage and is **ready but not started**.

Before doing any work, read [authoritative/START_HERE.md](authoritative/START_HERE.md).

## Five-stage programme

1. **Scaffold / Bootstrap** — authority, workflow, schemas, gates, success criteria.
2. **Research** — review a substantial corpus of published Problem Corner problems and solutions and derive an evidence-based editorial specification.
3. **Discovery** — generate a diverse, mathematically sound pool of serious candidate problems.
4. **Prior-art / Novelty Audit** — investigate visible and mathematically equivalent prior art for every serious candidate.
5. **Formalisation and Submission Package** — freeze, prove, test, re-audit, and prepare the final submission package.

The order is mandatory: serious candidate invention must not precede completion of the Stage-2 gate.
